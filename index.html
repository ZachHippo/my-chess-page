About the game

Chess is a two-player strategy game played on an 8x8 board of alternating light and dark squares — just like the one above. Each side starts with 16 pieces, and the goal is to checkmate the opponent's king: trap it so it can't escape capture. The board above is a simplified version — click a piece to see where it can legally move, then click a highlighted square to move it there. The game here ends when a king is actually captured, rather than using full checkmate/check rules.

A few fun facts

  • The number of possible unique chess games is far greater than the number of atoms in the observable universe.
  • The longest official chess game lasted over 269 moves.
  • Chess has been played for over 1,500 years, evolving from an Indian game called chaturanga.
  • The fastest possible checkmate is called the "Fool's Mate" — just 2 moves.
